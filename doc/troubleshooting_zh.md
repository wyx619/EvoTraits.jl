# 常见问题与排查

[English](troubleshooting.md) · [目录](README_zh.md) · [拟合](fitting_zh.md)

| 现象 | 检查点 | 处理方式 |
| --- | --- | --- |
| 对齐时报树上物种无记录 | 精确名称、同物异名、空白字符 | 统一名称或明确裁树，再对齐 |
| 重复 taxon 报错 | 每物种是否有多条来源记录 | 按明确规则汇总 |
| 使用了意外的性状列 | 数字元数据或多个数值性状 | 指定 trait_col 或先显式选列对齐 |
| 矩阵整行或整列缺失 | 每行每列至少一个观测 | 调整分析集合，不用零填补 |
| 映射或 regime 数量错误 | 树身份、枝段时长、标签 | 成对读取或裁剪树与映射 |
| Newick 解析失败 | 末尾分号、格式损坏 | 修正源语法，不直接拼接多树 |
| 预算耗尽 | 函数调用数及停止原因 | 提高预算；接口支持时比较其他起点 |
| logLik 有限但未收敛 | 有效求值与优化停止的区别 | 保留诊断，不称其收敛 |
| OU 最适值异常 | 均值设计的秩、regime 时长 | 检查 mean_diagnostics 及映射 |
| ASR 大量相同值 | alpha × 枝长、是否接近 theta | 检验 OU 记忆丧失及可识别性 |
| 对数性状 theta 为负 | 输入尺度 | 对数最适值允许为负 |
| EnvExp beta 很极端 | 环境缩放、覆盖、平滑 | 检查速率曲线及求积敏感性 |
| 批处理很慢 | 编译、嵌套并行、内存 | 分开记录准备与拟合，先测单例 |
| 时间零点汇总异常 | 额外全树基准行 | 绘图前去掉首行 |

## "根概率与预期不符"

先检查读取的是 `root_prior_probs` 还是边际重建，再按根 ID 定位，保留状态顺序检查全部概率。参见[根后验提取](discrete_zh.md)。

## "启动八线程为什么只拟合一次"

Julia 线程是可用工作资源，不是自动重复次数。corHMM 默认一次 trial、一个请求工作线程，须分别设置。连续家族有自己的候选调度，不要传入不存在的线程关键词。

## "最小 AIC 是否证明分类正确"

AIC 评价给定似然及候选集合。不同离散编码改变观测；不同 SIMMAP 条件下的连续模型需评估历史敏感性。参见[比较规则](workflows_zh.md)。

## "还能使用旧的根参数吗"

应使用当前公开名称：根均值 `:regime` / `:stationary`，根协方差 `:fixed` / `:random`，且须符合模型支持范围。OUMV/OUMA/OUMVA 仅支持 `:regime + :fixed`，不提供独立自由根均值估计。旧验证脚本中的已移除组合不能直接沿用。

## 如何报告可复现问题

提供包与 Julia 版本、完整函数调用、小树、对齐观测，必要时提供对应 SIMMAP、固定种子及完整报错。似然差异问题还应包含收敛信息和固定参数对照。不要只提供截图或单个 AIC 数值。
